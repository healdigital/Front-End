3. Proposal: One-Page “Recipe-First” Layout
3.1 Guiding principles
Everything on one page — vertical scroll rather than tabs. Scrolling is natural;
tabs are not.
Visual sections — clear separators with section titles and collapsible groups.
Recipe-first — the recipe is the main content, not a “block” to add.
Auto-generated fields — Slug, SEO title, per-serving calories computed
automatically.
Progressive disclosure — advanced fields SEO, detailed nutrition, personal
notes) go into collapsible sections at the bottom.

5. Implementation Recommendations (Payload CMS)
5.1 Structural changes
Remove the tab system — replace with Payload collapsible  groups
Remove “Recipe Blocks” array — recipe fields become direct fields in the
collection (no intermediary block)
Merge “Content” and “Recipe” — article rich text becomes an optional
collapsible section
Merge “Images” — featured media moves into the header
SEO →  collapsible section with default values auto-generated from title +
excerpt
Split “Metadata”:
Author, Categories, Tags →  header
Language →  header
Date, Original Link, Ready for publication →  collapsible “Publication”
section
